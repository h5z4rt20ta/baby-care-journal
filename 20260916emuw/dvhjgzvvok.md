# 【成中医生殖妇幼】祝贺我院“健康中国行 我们在行动”玉北社区惠民义诊活动圆满结束

> 更新时间：2026-09-16 (UTC+8)

**点击蓝字关注我们**

    为践行“党建惠民”，切实增强人民群众对“健康中国行动”的获得感，让辖区群众在家门口就能享受到优质的医疗咨询服务，**9月21日上午，由成都中医药大学附属生殖妇幼医院、四川省卫生健康宣传教育中心、武侯区玉林街道办事处玉林北路社区主办，四川12320卫生热线、四川省中药饮片有限责任公司协办，共同开展了“健康中国行、我们在行动”的主题惠民义诊活动。**

活动现场

尹巧芝副教授现场致辞

     上午9点，义诊活动在社区腰鼓队欢快的鼓点中拉开帷幕，我院副院长尹巧芝博士（副教授）、四川12320卫生热线中心主任刘硕、玉林北路社区党委书记向万军对本次活动进行了热情洋溢地致辞。

     此次活动现场设舞台区、义诊区、12320健康咨询区，吸引了大量社区群众前来参与，现场气氛热烈。活动开展了精彩的文艺表演活动。我院的医务工作者，为居民免费提供高血压、冠心病、糖尿病、妇科疾病、辅助生育、儿童保健、男性健康、中医康复等医疗咨询服务，并给予实际健康指导。

     参加活动的彭阿姨告诉记者：“对于老年人来说，健康是第一位的，这次活动把健康送到了家门口，对于我们来说很有意义，一些小病家门口就可以看了。医生认真负责，让我很感动、感谢。”

**八段锦表演和示教**

     我院老师同学们在现场进行了“八段锦”健身气功的示范讲解及互动教学，为社区居民普及健康运动增添了亮点。

     在《实施健康中国行动的意见》主要任务图解展区，12320咨询员对有健康需求的社区居民进行了详细的指导讲解，得到了群众的一致好评。

     此次义诊活动共接待群众300多人次，受到了群众的热烈欢迎。家住玉北社区的刘玉兰阿姨说：“我们大家要珍惜当下的生活，希望大家保重身体，现在生活这么好，我们要多活几十年！”

    通过这次综合性“党群共建”的义诊活动，增强了人民群众对医疗资源及“党建惠民”的获得感，增进了社区居民对“健康中国行动”的理解与感悟。践行了党群共建、突出“健康中国行”主题并树立了医疗惠民、健康知识普及的正面公益形象。

**医院简介**

      成都中医药大学附属生殖妇幼医院是经四川省卫生厅批准，以中西医生殖健康、优生优育为特色优势的医疗机构。是四川省卫健委直属32家公立医院之一、省发改委省属19家公立医院之一、西南地区唯一的世界卫生组织人类生殖研究合作中心、联合国人口基金南南合作培训中心。

      医院以辅助生育为特色，开设有生殖医学中心（丈夫精液人工授精技术、体外受精——胚胎移植技术及其衍生技术）、妇科、外科、内科、中医科、中医儿科、中西医结合科、皮肤科、口腔科、中医耳鼻喉科、麻醉科、医学影像科和医学检验科、药剂科等。
