# 一岁半宝宝便秘小妙招

> 更新时间：2026-09-16 (UTC+8)

一岁半宝宝便秘不舒服，排出的大便硬硬的，拉完屁股火辣辣的，宝宝自己也不好受，难过的时候可能还会哭闹，爸爸妈妈看在眼里，也是非常心疼啊。别急，小编来给大家支小妙招啦！一岁半宝宝便秘到底有什么招呢？

**一岁半宝宝便秘小妙招**

1. 腹部按摩法。宝宝便秘，排除的大便就会是又干又硬，这样会使他的肛门产生疼痛感，从而不敢用力，久而久之便秘就会更加严重，这个时候妈妈可以用手掌在宝宝的腹部轻轻的按摩，按摩腹部能加快肠胃蠕动，促进肠胃的血液循环，对宝宝排便起到很大帮助。以肚脐为中心，顺时针边揉边推，一般按摩10分钟左右，每日反复几次，坚持一周左右就会好转。

2. 喝金银花露。这个方法是我家孩子的姑奶奶当时告诉我的，而且通过我家宝宝试过的确很管用。小宝宝长期以奶粉为主食，很容易上火，金银花露具有清热解毒的功效，而且是金银花的蒸馏水，相交于其他药物更加安全，而且味道甘醇，容易被宝宝接受，价格也不贵，用于治疗宝宝便秘效果也不错。

3. 开塞露肥皂条。如果宝宝已经有几天没有排便了，妈妈们就要赶快采取措施，借助外力帮助宝宝排便，去药店买开塞露，让宝宝侧卧，把开塞露顶端剪开，然后轻轻插入肛门，用力挤压后端，使药物全部注入肛门内，然后退出空壳扨掉，这种效果很快。

4. 用热水坐浴法。用一个盆子装热水，温度要合适，不能烫着宝宝，抱住宝宝的两腿，让其屁股浸入水中，持续泡两分钟后抱出来，休息两分钟又让其浸入水中，如此反复几次即可，热水能使肛门周围血液循环加快，从而刺激直肠，进而加快蠕动，热水还可以使肛门括约肌得到放松，进而有助于排便。

**宝宝便秘吃什么好？**

1.马蹄海蜇汤：马蹄60克，海蜇50克。煎水饮用。

2.香蕉煮冰糖：香蕉2条，冰糖适量，加水煮汤食。

3.菠菜汤：菠菜150克，麻油适量，将菠菜煮熟，加盐调味，用麻油拌食。

4.蜂蜜甘蔗汁：蜂蜜、甘蔗汁各半杯拌匀，每日早晚空腹饮。

5.沙葛汁：沙葛去皮，捣烂绞汁，蜂蜜适量。用凉开水冲服。

6.大黄泡水：大黄3—5克，放入杯内，用沸水（约半杯）泡15分钟，加入蜂蜜少许服用。适用热结较甚。但不宜长期服用。
