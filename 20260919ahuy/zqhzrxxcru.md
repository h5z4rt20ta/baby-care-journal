# 异常胎位影响分娩胎位检查很有必要做

> 更新时间：2026-09-19 (UTC+8)

胎位检查有必要做吗？本期PCbaby亲子课堂邀请邓敏端为大家解答。

　　产前检查是保证母婴健康的一个重要的手段，每个准妈妈都要按时进行检查，通常来说在怀孕28周以后就要开始检查胎儿方位。正常的胎位是指宝宝倒立在准妈妈的肚子里，头是在肚子的下方，屁股朝上，后脑勺是朝向前面，那么除了这个方位之外，所有的其他地胎位我们都认为它是不正常的胎位。

　　那么不正常的胎位总体来说包括了脸朝向前面的这种枕后位，还有一种是叫臀位，臀位是胎儿的屁股向下呈蹲着这样一个状态，还有一种更少见的叫作横位，就是胎儿是横着躺在肚子里面。胎位不正会给孕妇自然分娩带来一个很大的干扰，甚至有时候还会引起脐带脱垂、胎死宫内，子宫破裂等等这样的风险。

　　当然了，孕妈妈们也不用太过于担心，那么在怀孕28周之前大多数的宝宝在准妈妈的肚子里面是可以自由活动的，这个姿势还没有固定，一般来说要到怀孕32周以后这个姿势和位置才基本固定。在怀孕28～34周之间这是纠正胎位不正的一个最佳时机，假如在怀孕28周的时候通过检查发现有胎位不正的情况，这个时候要咨询医生，由医生根据孕妇的具体情况做出决定能否进行胎位的矫正。@font-face { font-family: 宋体;}@font-face { font-family: "Cambria Math";}@font-face { font-family: Calibri;}@font-face { font-family: "@宋体";}p.MsoNormal, li.MsoNormal, div.MsoNormal { margin: 0cm 0cm 0.0001pt; text-align: justify; font-size: 10.5pt; font-family: "Calibri", sans-serif; }.MsoChpDefault { font-size: 10pt; font-family: "Calibri", sans-serif; }div.WordSection1 { }
